📖 台灣正宗十三張規則 & GitHub 圖庫說明

📁 GitHub Pages 本機圖庫放法
將此檔存為 index.html，同目錄建立 images/ 資料夾並放入 1.jpg ～ 13.jpg（系統也會自動偵測 .png 與 .webp）。
1. 流暢擺牌與防倒水（相公）
每人 13 張牌，分成 頭墩(3張)、中墩(5張)、尾墩(5張)。點手牌自動放入紅框墩位；點已擺的牌再點任一張牌可直接互換（點同張兩次收回手牌）。
須滿足 尾墩 ≥ 中墩 ≥ 頭墩，違反即「倒水（相公）」，無條件輸給所有未倒水玩家並以打槍倍數賠付。
2. 牌型大小（只比點數不比花色）
同花順 > 鐵支 > 葫蘆 > 同花 > 順子 > 三條 > 兩對 > 一對 > 烏龍。
A 最大、2 最小，同點平手 0 水。順子以 10-J-Q-K-A 最大，A-2-3-4-5 第二大。
3. 單墩加水、打槍與全壘打
  • 頭墩三條（衝三）：3 水 ｜ 中墩葫蘆：2 水
  • 尾墩鐵支：4 水 ｜ 中墩鐵支：8 水
  • 尾墩同花順：5 水 ｜ 中墩同花順：10 水
  • 打槍：三墩全贏同一家，該家總水數 ×2。
  • 全壘打：打槍全部 3 家，總水數 再 ×2！
4. 5 種報到特殊牌型（免比牌直接收水）
至尊青龍（26 水）、一條龍（13 水）、三同花 / 三順子 / 六對半（各 3 水）。
